# For Designers

Widgetbook Cloud has two audiences: the developers who build the UI, and the designers who own how it should look. The rest of these docs are written for developers. This section is for designers.

Every pull request produces a [review](/cloud/reviews) that opens in a browser. No Flutter, no local checkout.

<Image theme="light" src="/assets/cloud/review.light.png" />
<Image theme="dark" src="/assets/cloud/review.dark.png" />

## The Two-Stage Review

| Stage | Who | Question |
| --- | --- | --- |
| 1. Filter | The developer who opened the pull request | Did I change anything I did not mean to? |
| 2. Judge | The next reviewer, often a designer | Are the intentional changes correct? |

Stage 1 is a filter. A review that reaches a designer should contain only deliberate changes, so a designer judges intent rather than hunting for accidents.
