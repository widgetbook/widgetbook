# Addons in Cloud

[Addons](/addons/overview) are configured in your Widgetbook project, not in Widgetbook Cloud. Cloud reads the result: every [mode](/addons/modes) you pin on a scenario becomes one [snapshot](/cloud/snapshots/overview) in the build.

```
snapshots = scenarios × pinned mode combinations
```

An addon on its own costs nothing. Only a mode pinned on a story or a scenario produces a snapshot.

## What Each Addon Covers

| Addon | Mode | Catches |
| --- | --- | --- |
| [Theme](/addons/theme-addon) | `MaterialThemeMode`, `CupertinoThemeMode`, `ThemeMode` | Hardcoded colors, unreadable contrast in the other brightness |
| [Locale](/addons/locale-addon) | `LocaleMode` | Untranslated strings, overflow from longer translations, RTL layout |
| [Viewport](/addons/viewport-addon) | `ViewportMode` | Layout breaking on small phones or wide tablets |
| [Text Scale](/addons/text-scale-addon) | `TextScaleMode` | Clipping and overlap at accessibility text sizes |
| [Alignment](/addons/alignment-addon) | `AlignmentMode` | Intrinsic sizing bugs on unconstrained widgets |
| [Semantics](/addons/semantics-addon) | `SemanticsMode` | Nothing extra in Cloud, the semantics tree is captured for every scenario regardless |

[Zoom](/addons/zoom-addon), [Grid](/addons/grid-addon), and [Time Dilation](/addons/time-dilation-addon) are browsing aids. Pinning them as modes produces snapshots that are rarely worth reviewing.

## Story Modes vs Scenario Modes

A mode on a story applies to all of its scenarios. A scenario mode overrides a story mode of the same type.

```dart title="widgetbook/lib/button.stories.dart"
final $Primary = _Story(
  // Every scenario below renders on an iPhone 13.
  modes: [ViewportMode(IosViewports.iPhone13)],
  scenarios: [
    _Scenario(name: 'Light'),
    _Scenario(
      name: 'Dark',
      // Keeps the viewport, adds the theme.
      modes: [MaterialThemeMode('Dark', ThemeData.dark())],
    ),
  ],
);
```

Two scenarios, two snapshots. See [How Modes Are Merged](/testing/create-scenario#how-modes-are-merged).

## Building a Matrix

To cover a component across a set of configurations, generate the scenarios instead of writing them out:

```dart title="widgetbook/lib/button.stories.dart"
final themes = {
  'Light': ThemeData.light(),
  'Dark': ThemeData.dark(),
};

final $Primary = _Story(
  scenarios: [
    for (final entry in themes.entries)
      _Scenario(
        name: entry.key,
        modes: [MaterialThemeMode(entry.key, entry.value)],
      ),
  ],
);
```

<Warning>
  A full cross product grows multiplicatively. 3 themes × 4 locales × 3 viewports is 36 snapshots for a single story. Pick the combinations that can actually break. See [Optimize Builds](/cloud/configure/optimize-builds).
</Warning>
