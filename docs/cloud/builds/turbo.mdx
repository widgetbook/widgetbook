# Turbo Builds ⚡

`widgetbook cloud build push` hashes the build contents before uploading. When the hash matches an existing build, Widgetbook Cloud reuses that build instead of uploading and processing it again, and the new commit gets its build instantly.

This means a commit that only touched build-irrelevant files, such as tests, a README, or CI config, costs no upload time and no extra [snapshots](/cloud/account/billing).

Turbo Builds are enabled by default.

## Caveats

The hash only covers the build contents, so it cannot detect a change in something the build fetches at runtime:

- External URLs, such as remote images, whose content changed while the URL stayed the same.
- Network requests that change how a story renders.

## Disable

```bash
widgetbook cloud build push --no-turbo --api-key <API_KEY>
```

See [Optimize Builds](/cloud/configure/optimize-builds) for the other ways to cut unnecessary uploads.
