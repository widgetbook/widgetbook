# Submit a Review

The diff view shows the `base` version on the left and the `head` version on the right, one entry per changed scenario.

<Image src="/assets/cloud/visual-pull-request/example.png" zoom />

## Inspect a Change

| Action | Where | Effect |
| --- | --- | --- |
| **Show diff** | Top-right of a story diff | Highlights the changed pixels in pink |
| **Mark as viewed** | Top-right of a story diff | Tracks progress. Resets when the story changes again |
| **Comment** | Comment section of a story diff | Ties feedback to that exact scenario |

<Image src="/assets/cloud/reviews/show-diff.png" zoom caption="Show diff highlights the changed pixels" />
<Image src="/assets/cloud/reviews/mark-as-viewed.png" zoom caption="Mark as viewed tracks which stories you already checked" />

## Publish a Decision

Click **Review changes** in the top-right corner and pick a status.

<Image src="/assets/cloud/reviews/example.png" zoom />

| Status | Commit status | Merge |
| --- | --- | --- |
| **Approved** | Successful | Allowed |
| **Comment** | Pending, unless another status overrides it | Not affected |
| **Changes requested** | Failed | Blocked until revised |

<Info>
  With [required reviewers](/cloud/reviews/required-reviewer) configured, at least one required reviewer must approve before the visual pull request counts as approved.
</Info>
