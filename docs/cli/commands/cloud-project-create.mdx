# `cloud project create`

Creates a project in your Widgetbook Cloud workspace.

Creating a project is a one-time setup step.
Run the command once when you set up a project, or in your CI pipeline with `--allow-existing`, so that every run after the first one succeeds as well.

## Usage

```bash
widgetbook cloud project create --api-key <API_KEY> --project my-app
```

## Arguments

The CLI accepts the following arguments.

| Argument           | Mandatory | Description                                                                                         |
| ------------------ | --------- | --------------------------------------------------------------------------------------------------- |
| `--api-key`        | ✅        | An [API key](/cloud/api-keys) with the "Create projects" permission.                                |
| `--project`        | ✅        | The name of the project to create.                                                                  |
| `--allow-existing` | ➖        | Exit successfully instead of failing when a project with this name already exists in the workspace. |
| `--api-url`        | ➖        | Base URL of the Widgetbook Cloud API. Defaults to `https://api.widgetbook.io/`.                     |

## Project name

Project names are unique within a workspace.

Your pipelines refer to the project by this name through the `--project` argument of [`cloud build push`](/cli/commands/cloud-build-push) and [`cloud review skip`](/cli/commands/cloud-review-skip).
If you rename the project in Widgetbook Cloud, update `--project` in your pipelines as well.

## Behavior

If a project with the same name already exists in the workspace, the command fails.
With `--allow-existing`, it exits successfully instead and leaves the existing project unchanged.

The command creates the project without a Git connection.
To synchronize pull requests and get reviews, [connect the project to your repository](/cloud/projects/connect#connect-project).
