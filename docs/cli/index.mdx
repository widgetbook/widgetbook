# Overview

The CLI is available as the [widgetbook_cli](https://pub.dev/packages/widgetbook_cli) package.

```
# 🎯 Activate from https://pub.dev
dart pub global activate widgetbook_cli {{ versions.cli }}

# 🚀 Use CLI
widgetbook <command> [arguments]
```

## Commands

The CLI provides the following commands:

- [init](/cli/commands/init)
- [cloud project create](/cli/commands/cloud-project-create)
- [cloud build push](/cli/commands/cloud-build-push)
- [cloud review skip](/cli/commands/cloud-review-skip)
- [coverage](/cli/commands/coverage)
- `upgrade`: update the CLI to the latest version

Run `widgetbook --version` to print the installed CLI version.

## Authentication

The `cloud` commands authenticate with an [API key](/cloud/workspaces#api-keys), passed with `--api-key`.
You create API keys in your Widgetbook Cloud workspace settings, under **API keys**.
