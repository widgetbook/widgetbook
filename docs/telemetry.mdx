# Telemetry

Widgetbook reports usage information to help us improve the package
and to understand which organizations use Widgetbook.
The data is pseudonymous: it does not include your name or email address,
but some of it, like a repository owner URL, can relate to a person.
We use it at organization level only.

## Opting-out

To opt-out from telemetry:

1. Create a `build.yaml` file at the root of your project (next to your `pubspec.yaml`).
1. Add the following content to the file:

   ```yaml
   targets:
     $default:
       builders:
         widgetbook:telemetry:
           enabled: false
   ```

## Collected Data

A new telemetry report is sent after you run the `build_runner build` command,
if the `components.g.dart` file has changed.

We send the following information:

1. The package name.
1. A **hashed** ID based on your git config email. We do not try to link it to a person.
1. The SHA of the first commit in the repository, to identify distinct projects.
1. The repository's owner URL (e.g. `https://github.com/widgetbook`).
   For personal repositories, this contains your username. We remove usernames before analysis.
1. Information about Widgetbook Components like:
   - The number of components.
   - The number of components with various counts of stories.
   - The packages' names where the components were defined.

## How We Use It

- To improve the generator and decide what to build next.
- To understand which organizations use Widgetbook, and to contact organizations
  that may benefit from Widgetbook Cloud. We never mention telemetry data in that contact.

The data is processed by Mixpanel (EU data residency).
For legal basis, retention and your rights, see Section 4d of our
[Privacy Policy](/cloud/account/privacy-policy).
